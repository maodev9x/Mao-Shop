# Quy trình làm việc

1. Dựng layout (TopBar, Header, Footer) và design token trước.
2. Làm các component `ui/` và `ProductCard`, sau đó ráp từng khối trang chủ theo thứ tự trong rule homepage-layout.
3. Mỗi khối xong thì đối chiếu với [UI.png](../../UI.png), kiểm tra cả desktop và mobile.
4. Trước khi báo hoàn thành: `npm run build` phải thành công (đã gồm kiểm tra type).
